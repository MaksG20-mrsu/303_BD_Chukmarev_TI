# Требования к запуску кода
На устройстве должны быть установлены:
- Python v.3
- SQLite

# Как запустить
Откройте терминал в Linux, либо командную строку в Windows (НЕ powershell), затем выполните команду
```bash
./db_init.bat
```
После должны создаться два файла: `db_init.sql` и `movies_rating.db`. В базе данных будут содержаться данные из файлов директории dataset
